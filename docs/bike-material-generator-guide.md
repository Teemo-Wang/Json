# 🚲 新车素材生成器 — 使用手册

> 哈啰两轮设计团队专用工具，用于新车上线时批量生成全套运营素材。

## 访问地址

- 在线版：https://teemo-wang.github.io/Json/docs/bike-material-generator.html
- 本地版：直接用浏览器打开 `docs/bike-material-generator.html`

---

## 快速上手

### 第一步：上传车辆图片

左侧面板「📷 车辆图片上传」区域，支持上传 4 张图片（PNG 格式）：

| 图片 | 用途 | 必须 |
|------|------|------|
| 左侧视图 | 车辆水平左侧照片 | 至少上传一张 |
| 右侧视图 | 车辆水平右侧照片 | 推荐 |
| 45度视图 | 车辆透视角度照片 | 推荐 |
| 车型Icon | 车型小图标 | 推荐 |

> 💡 工具内置了默认车辆图片，打开即可预览效果。上传新图片后会自动替换。

### 第二步：填写车型信息

「📝 车型信息 & 样式」面板：

- **车型名称**：会自动填入各素材的文案中（如"哈啰「冰川号」"）
- **短文案**：≤6字，用于部分素材的标语
- **主题色 / 背景色 / 文字色 / 副文字色**：点击色块选择颜色

### 第三步：生成素材

点击「🔄 生成全部素材」按钮，等待加载进度条完成后，所有素材会显示在右侧网格中。

### 第四步：编辑 & 导出

- 点击每张素材卡片上的「✏️ 编辑」按钮，打开编辑弹窗进行微调
- 点击「💾 导出」单独导出某张素材
- 点击「📦 一键导出全部」打包下载 ZIP 文件（按分类文件夹整理）

## 素材分类说明

工具生成 5 大类素材，通过顶部标签页切换筛选：

### A. 车辆样式配置
地图上的车型 icon（选中/未选中状态）、车辆静态卡片、车辆报障图、卡片背景等。

### B. 靓车信息配置
靓车卡片背景（780×1224）、靓车车辆图、车型卖点图、价格说明层、靓车频道列表卡片、投票小图等。

### C. 发现靓车活动页
发现靓车主图（1170×1527）、营销标题。

### D. 骑行高光
- **高光背景卡**（1098×1272）：带 icon + "首次骑到" 文案，渐变背景可调色
- **高光车辆**（1098×651）：车辆右视图 + 调色 icon
- **高光分享**（1098×1500）：渐变背景 + 双行标题 + 车辆右视图，文案/颜色/位置均可编辑

### E. 首页场景卡
车型名称文案（"辆 冰川号"），颜色可编辑。

## 编辑弹窗功能

点击素材卡片的「编辑」按钮后，弹窗分为左侧预览区和右侧控制面板。

### 通用控件（非 layered 素材）
- 水平/垂直位置、缩放、旋转
- 背景色选择、透明背景开关
- 文案内容编辑（如有）

### Layered 素材控件（可折叠面板）

| 面板 | 功能 |
|------|------|
| 🎨 渐变色 | 调整图层渐变的顶部/中间/底部颜色 |
| 🚲 车辆图 | 替换背景图/车辆图，调整位置/缩放/旋转 |
| 🎯 Icon | 调整 icon 位置/缩放/旋转 |
| 📝 顶部文案 | 编辑靓车卡片的文案前缀/后缀、字号、颜色、描边 |
| ✨ 高光文案 | 编辑 D1 的文案内容、文字色、字号 |
| ✨ 高光分享文案 | 编辑 D3 的上行/下行文案、字号、颜色、位置 |
| 📝 发现靓车文案 | 编辑副标题、车型名、颜色、位置 |
| 🏷️ 场景卡文案 | 编辑前缀、车型名、颜色 |
| 图层纯色 | 调整纯色填充图层的颜色 |

> 💡 每个面板标题可点击折叠/展开，节省空间。

## 导出说明

### 单张导出
- 素材卡片上点「💾 导出」
- 编辑弹窗中点「导出此素材」

### 批量导出
点击「📦 一键导出全部」，生成 ZIP 压缩包，内部按分类文件夹整理：

```
车型名称/
├── A-admin车辆样式配置/
│   ├── 车型icon（未选中）_180x180.png
│   ├── 车型icon（选中）_138x165.png
│   └── ...
├── B-admin靓车信息配置/
│   ├── 靓车卡片背景_780x1224.png
│   └── ...
├── C-发现靓车活动页配置-发现靓车频道头图/
├── D-百灵骑行结束高光配置/
│   ├── 高光背景卡_1098x1272.png

│   └── 高光分享_1098x1500.png
└── E-首页场景卡/
```

## 颜色关联机制

部分素材共享同一组渐变色（colorGroup），编辑其中一个的渐变色后，同组素材会自动同步更新：

- `icon-gradient`：A1/A3/A4 的 icon 渐变色联动
- `price-gradient`：B5 价格说明层
- `b6-gradient`：B6 靓车卡片图

## 常见问题

**Q：在线版导出卡住怎么办？**
A：在线版可能因跨域限制导致部分素材导出失败，建议下载到本地后用浏览器直接打开 HTML 文件导出。

**Q：文字显示不是造字工房元黑体？**
A：需要确保 `docs/fonts/MFYuanHei-Regular.otf` 字体文件存在。在线版会自动加载。

**Q：如何更换默认车辆图片？**
A：替换 `docs/Bicycle Page/A/A-bike/` 目录下的对应图片文件即可。

**Q：素材尺寸不对怎么办？**
A：每张素材的尺寸是固定的（如 1098×1272），在卡片右上角有尺寸标签。编辑时调整的是车辆/icon 在画布内的位置和缩放。
